Before You Start

What You Need Before This Works

You need Claude Code connected to GoHighLevel via MCP. Run this command in your terminal and replace YOUR_PIT_TOKEN with your GoHighLevel Private Integration Token.

claude mcp add --transport http gohighlevel \ https://services.leadconnectorhq.com/mcp/ \ --header "Authorization: Bearer YOUR_PIT_TOKEN" \ --header "Version: 2021-07-28"

To get your Private Integration Token:
GHL → Settings → Private Integrations → Create New Integration

Once that's live, every prompt below runs inside your Claude Code terminal and reads directly from your GHL data.

The Prompt Sequence

5 Prompts. Start to Close.

Prompt 1 — Find the forgotten deals (this is the 11 seconds)

Paste this exactly into your Claude Code terminal:

Copy & Paste
Look at my GoHighLevel pipeline. Find all opportunities that
haven't been updated in the last 30 days, are still open
(not won or lost), and give me a list sorted by how long
since we last touched them. For each one show me:
contact name, phone number, email, pipeline stage,
and days since last activity.

That's the pull. Claude queries GHL and returns the list. That's your 47 deals.

Prompt 2 — Add context so you know what to say

Copy & Paste
For each of these contacts, check their conversation history
and any notes in GHL. Tell me the last thing that was said
or done with each person — what stage we left off at and
whether they ever expressed interest in moving forward.

Now you don't just have a list. You have context for every name on it.

Prompt 3 — Sort by likelihood to close

Copy & Paste
Now sort these contacts into three groups based on what
you found:

HOT  — They expressed real interest but we lost touch
WARM — They engaged but never committed
COLD — Minimal engagement, little signal either way

Show me the HOT group first with a one-sentence summary
of where we left off with each person.

Work the HOT group today. Warm group this week. Cold group gets an automated sequence.

Prompt 4 — Write the re-engagement messages

Copy & Paste
For every contact in the HOT group, write me a
personalized re-engagement text message based on
what we last talked about.

Rules:
- 2-3 sentences max
- Reference something specific from our last conversation
- Sound like I'm picking up where we left off, not starting over
- Never say "just checking in" or "circling back"
- End with one direct question that moves things forward
- Write it in first person as Sean

Claude writes a different message for every contact. Not a blast. Actual personalization from your own conversation history.

Prompt 5 — Load them into a follow-up sequence in GHL

Copy & Paste
For the WARM and COLD groups, create a 3-step follow-up
sequence in GoHighLevel:

Day 1: Text message — casual re-engagement, one question
Day 3: Email — brief value reminder, soft ask
Day 7: Text — final touch, direct offer or close the loop

Write the copy for each step. Keep the tone conversational.
No corporate language. Sound like a real person following up.
Closing Strategy

Three Moves for the HOT Group

Move 1

Send the message Claude wrote

Don't edit it to death. Send it. The goal is a reply, not a masterpiece.

Move 2

Qualify with one question when they reply

When they respond, send this:

"Quick question — is [the thing they were interested in] still something you're trying to figure out this month, or did that take a back seat?"

That question separates people still in buying mode from people who moved on. You need to know which one you're dealing with before you spend another minute on them.

Move 3

Book the call. Don't pitch in text.

If they say yes it's still relevant:

"Let's get 20 minutes on the calendar. Here's my link — [Calendly link]. Pick whatever works."

No pitch in the DM. No features, no benefits. Just the call.
