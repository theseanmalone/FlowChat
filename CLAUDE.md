## GHL MCP Setup (for video content and personal use)

**What MCP does:** Connects Claude Code directly to GHL so Claude can read/write contacts,
pipelines, conversations, tags, and opportunities in plain English — no copy-paste.

**Setup steps:**
1. GHL → Settings → Private Integrations → Create New Integration
   - Name: "Claude Code MCP"
   - Scopes: View Locations, View/Edit Contacts, View Pipelines,
     View/Edit Opportunities, View Conversations, View/Edit Tags,
     Edit Calendars, View Custom Fields
   - Copy the Private Integration Token (treat like a password)
2. GHL → Settings → Business Profile → copy Location ID
3. Run in terminal:
   ```
   claude mcp add --transport http gohighlevel \
     https://services.leadconnectorhq.com/mcp/ \
     --header "Authorization: Bearer YOUR_TOKEN" \
     --header "Version: 2021-07-28"
   ```
4. Start Claude (`claude`) then test: "List my 5 most recent contacts in GoHighLevel"

**5 demo use cases for video content:**
- "Show me all leads that haven't moved in more than 5 days"
- "Look up [Name], read their conversation, write a personalized follow-up"
- "Give me a summary of my pipeline — who needs attention today?"
- "Move [Name] from Contacted to Booked and tag as call-booked"
- "How many new leads came in this week and what was the source?"

## GHL SOP for Claude Projects

When Sean asks for GHL copy, workflows, or pipeline work, apply this context:

**Pipeline stages:** New Lead → Contacted → Booked → Proposal Sent → Closed Won → Closed Lost
**Follow-up rules:** First touch within 5 min of opt-in. Max 2x/week if no reply. 5 touches over 14 days then move to nurture. No sends before 8am or after 8pm. No Sunday sends.
**Voice:** Direct, warm, human. Sounds like Sean — not a company. Sign-off: — Sean
**Never:** "I hope this email finds you well" / multiple CTAs / corporate buzzwords
**Frameworks:** 4-Hinge DM (Relevance → Credibility → Curiosity → Ask) for first-touch. Good-Good-Bad for objection handling.
**Snapshot link:** go.closers-blueprint.com/snapshot
**GHL trial link:** https://www.gohighlevel.com/highlevel-bootcamp?fp_ref=3y2tor

### Key GHL Tags
Lead status: new-lead, contacted, call-booked, proposal-sent, closed-won, closed-lost, not-qualified
Sequence: in-sequence, sequence-complete, nurture-sequence, opted-out
Source: source-youtube, source-podcast, source-referral, source-dm, source-paid
Product: snapshot-requested, dfy-interested, flowchat-ai-interested, affiliate-ghl
Client: active-client, review-requested, review-received

### Key Automations
- Missed Call Text-Back: fires within 2 min → SMS "Hey [First Name] — missed your call. What's the best time to connect? — Sean"
- Snapshot Delivery: form submit → immediate email with snapshot link → tag: new-opt-in → pipeline: New Lead → 10-min SMS
- No Reply Follow-Up: 3 days no reply → follow-up #2 → after 5 attempts → Long-Term Nurture
- Closed Won Onboarding: stage change → onboarding email → tag: active-client → remove from sales sequences
- Reputation Management: 30 days post-close → review request SMS → no reply → follow-up email day 35
